# CourseHub - Demo Project

Hệ thống hỗ trợ tra cứu và đăng ký lớp học phần (Môn học: Cơ sở dữ liệu Web và hệ thống thông tin - TS. Vũ Tiến Dũng & Phạm Duy Phương).

## 1. Giới thiệu
CourseHub là hệ thống mô phỏng phục vụ cho các bài thực hành học phần Cơ sở dữ liệu Web và hệ thống thông tin.
- **Buổi 1**: Ôn tập Python cơ bản, mô phỏng dữ liệu bằng List & Dictionary, tổ chức project và quản lý mã nguồn với Git/GitHub.
- **Các buổi tiếp theo**: Phát triển Backend với FastAPI, kết nối Cơ sở dữ liệu PostgreSQL và tích hợp giao diện Frontend.

## 2. Cấu trúc thư mục
```text
CourseHub/
├── .gitignore
├── README.md
└── backend/
    └── week01_python_refresh.py
```

## 3. Hướng dẫn chạy chương trình (Buổi 1)
Yêu cầu: Python 3.11 trở lên đã được cài đặt và cấu hình PATH.

Chạy chương trình từ thư mục gốc của project:
```bash
python backend/week01_python_refresh.py
```
